## 🌐 Free 2-Minute Deployment to GitHub Pages

1. Create a repository on GitHub (e.g. `osama-portfolio` or `username.github.io`).
2. Run inside this folder:
   ```powershell
   git init
   git add .
   git commit -m "Initial portfolio release"
   git branch -M main
   git remote add origin https://github.com/<your-username>/osama-portfolio.git
   git push -u origin main
   ```
3. In GitHub: **Settings** &rarr; **Pages** &rarr; Source: `main` &rarr; Click **Save**.
4. Your website is immediately live!
