Integrated Waste‑to‑Electricity System

An interdisciplinary team built a steam-turbine plant that turns waste into electricity. I owned the software: the monitoring and safety system, a local API gateway, the edge data layer and the operator dashboard — all of it designed to run with no network connection at all.

Sensors on the boiler stream temperature, pressure and voltage through an Arduino, built by the team’s electrical engineer. The dashboard shows every reading live and raises an emergency alarm the moment chamber pressure reaches the 60 PSI safety limit. Every reading is stored in an append-only log where each entry is SHA-256 chained to the one before, so any edit or deletion is detected. A built-in simulator lets the whole stack run without the hardware rig.

KFUPM Study Hub

A platform for KFUPM students to track assignments, exams and projects on a calendar, get email reminders before deadlines, and share course material through a moderated upload queue.

The interesting part was access control. Passwords are hashed with bcrypt, sessions are JWTs, and every route checks one of three roles, so approval and admin actions can't be reached by tampering with the client.

Unplanned shutdowns at a petrochemical plant are expensive. For the Asset Health Care project I built a predictive-maintenance pipeline that flags pumps, piping and sensor clusters drifting away from normal behaviour — under an enterprise rule that no custom code was allowed, so every step lives natively in RapidMiner.

  1. Clean
    195,033 raw records

  2. Model
    • One-Class LIBSVM RBF kernel, ν = 0.03

    • Influenced Outlierness INFLO

    Three unsupervised detectors tuned across multi-sensor dimensions.

  3. Explain

    A post-processing layer keeps only anomalies sustained for two hours or more and ranks the sensors contributing most — output that engineers can act on. Approved by department leadership.
